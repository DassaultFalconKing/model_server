## Scope rule

Refit protocol semantics, not the 2026.5 runtime. Never wholesale cherry-pick the 2026.5 migration range. Exclude OpenVINO/GenAI 2026.5 pins, version bumps, GPU/performance tuning, prefix-cache experiments, package-runtime substitutions, and unrelated upstream changes.

## Work packages

1. **Reasoning semantics RED/GREEN**
   - Port the dedicated Gemma4 reasoning parser contract.
   - Remove Qwen3 inheritance.
   - Add `toolStartTerminatesReasoning` only as a tolerant recovery boundary.
   - Preserve reasoning prefix and hold partial tool markers at the reasoning/tool handoff.
   - Fix implicit prompt-open reasoning detection for whitespace-terminated Gemma4 tags.

2. **Tool parser hardening RED/GREEN**
   - Preserve recursive native argument parsing and lexical JSON numbers.
   - Fail closed for malformed numeric-looking scalars.
   - Keep request-registry enforcement.
   - Bound bare `call:` recovery to native line-prefix shapes and never swallow ordinary prose at EOF.
   - Preserve repeated same-tool calls and unique call identities; add the `fde0762` delta only from exact source/evidence, not by guesswork.

3. **Generation policy RED/GREEN**
   - Port required/named hard grammar semantics.
   - Port lazy/triggered `tool_choice=auto` semantics using OpenVINO GenAI `TriggeredTags` where supported by the 2026.4 runtime API.
   - Preserve `parallel_tool_calls` policy.
   - No empty `ConstString("")`; hard validation remains fail-closed.

4. **Rendered prompt-state adaptation RED/GREEN**
   - Adapt hard grammar after chat-template rendering when the prompt already ends inside Gemma4 reasoning.
   - Keep the adaptation request-independent at the template processor boundary.
   - Port only the minimum analyzer/caps/adapter/processor changes required by the contract.

5. **Streamer / special-token boundary RED/GREEN**
   - Preserve structural special-token boundaries across reasoning -> tool phase handoff.
   - Prevent partial marker leakage and premature turn closure.

6. **OpenAI API surface RED/GREEN**
   - Refit `parallel_tool_calls` request propagation and response serialization required by the protocol tests.
   - Do not pull unrelated 2026.5 API behavior merely because it shares a file.

7. **Session continuity: deferred by default**
   - `servable.*` is outside the parser blast radius unless a focused multi-turn contract demonstrates an unavoidable dependency.

## Comparison gates

## Acceptance hierarchy

Source/contract GREEN is not runtime acceptance. Final candidate must be built and packaged against the exact 2026.4 runtime pins, then run through synthetic parser/generation tests, streaming tests, repeated-same-tool tests, multi-turn tool-loop tests, and a real OpenCode workload on Arc 140V.

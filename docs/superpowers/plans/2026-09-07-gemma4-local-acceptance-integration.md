# Gemma4 Local Acceptance Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce one exact, reproducible `integration/gemma4-local-acceptance-2026.4` candidate that combines the current Gemma4 generation/API spine with the five parser-hardening commits, proves all offline contracts, and emits a Windows-ready local acceptance bundle whose full PASS promotes that exact SHA to `MAINTAINER_PR_SOURCE`.

**Architecture:** Treat `fix/gemma4-responses-parallel-tool-policy` as an immutable integration spine and replay only the five commits unique to `fix/gemma4-parser-hardening-post-f36d2d75`, in order, with focused regression tests after every replay. Keep runtime code changes separate from acceptance tooling: parser/generator/API code is modified only when an explicit contract test fails, while `ab-evidence/local_acceptance_gate.py` orchestrates provenance, offline gates, and the live Windows matrix using the existing reliability and chained-session harnesses.

**Tech Stack:** C++17, OpenVINO Model Server 2026.4 lineage, OpenVINO GenAI `StructuredOutputConfig`, xgrammar, RapidJSON, GoogleTest, Bazel, Python 3 standard library, Windows PowerShell for the final local-machine build/run wrapper.

**Spec:** `docs/superpowers/specs/2026-09-07-gemma4-local-acceptance-integration-gate-design.md`

```python
import unittest

import local_acceptance_gate as gate


class LocalAcceptanceGateTests(unittest.TestCase):
    def test_full_required_pass_is_local_accepted(self):
        results = {name: "PASS" for name in gate.REQUIRED_CASES}
        self.assertEqual(gate.aggregate_verdict(results), "LOCAL_ACCEPTED")

    def test_any_required_non_pass_is_not_local_accepted(self):
        for verdict in ("FAIL", "ERROR", "NOT_RUN", "BLOCKED_BY_PLATFORM"):
            with self.subTest(verdict=verdict):
                results = {name: "PASS" for name in gate.REQUIRED_CASES}
                results[gate.REQUIRED_CASES[0]] = verdict
                self.assertEqual(gate.aggregate_verdict(results), "NOT_LOCAL_ACCEPTED")

    def test_missing_required_case_is_not_local_accepted(self):
        results = {name: "PASS" for name in gate.REQUIRED_CASES[1:]}
        self.assertEqual(gate.aggregate_verdict(results), "NOT_LOCAL_ACCEPTED")
```

```python
REQUIRED_CASES = (

FINAL_FAIL = "NOT_LOCAL_ACCEPTED"


def aggregate_verdict(case_results):
```
